하루 흐름

매장 하루는 이 다섯 단계로 돌아갑니다. 각 단계의 자세한 방법은 아래에 있습니다.

  1. 입장이름과 비밀번호 1998 입력
  2. 오픈 점검진열 수량을 세어 입력 후 🌅 오픈 점검
  3. 판매·입고굿즈·체험 티켓 결제, 들어온 물건은 입고 등록
  4. 마감 실사영업 끝나고 다시 세어 실사 칸에 입력
  5. 마감하기🏁 마감하기로 업로드 + 실사 반영 후 잠금

퇴근 전에 꼭 🏁 마감하기를 누르세요. 인터넷이 불안정한 매장에 맞춰, 판매·입고·실사 기록은 먼저 이 기기에 보관되고 마감할 때 구글 시트에 한꺼번에 올라갑니다.

매일 00시~01시 사이에 그날의 판매 내역이 구글 시트에 날짜 이름(예: 2026-09-17)의 새 탭으로 자동 보관됩니다. 따로 할 일은 없습니다.

입장과 잠금

창을 열 때마다 이름과 비밀번호를 묻습니다. 입력한 이름은 모든 판매·입고 기록의 담당자로 남습니다.

  1. 주소창에 ssharebox.github.io/bread_stock을 입력해 엽니다. 휴대폰에서도 같은 주소로 쓸 수 있습니다.
  2. 이름을 쓰고 Enter를 누르면 비밀번호 칸으로 넘어갑니다.
  3. 비밀번호 1998을 입력하고 입장을 누릅니다.

자리를 비우거나 교대할 때

  • 오른쪽 위 🔒 잠금(휴대폰은 🔒 아이콘)을 누르면 화면이 바로 잠기고, 담아 둔 결제 목록도 비워집니다.
  • 다음 근무자가 자기 이름으로 다시 입장하면 됩니다. 지난번 이름이 미리 채워져 있으니 바꿔서 입력하세요.
  • 같은 창에서 새로고침(F5)할 때는 다시 묻지 않습니다.

판매하기 🧾 판매 탭

한 손님의 구매 한 번이 “결제 1건”입니다. 여러 상품을 담아 한 번에 결제하세요.

  1. 바코드를 찍거나, 왼쪽 상품 카드를 누르면 오른쪽 이번 결제에 담깁니다. 같은 상품을 다시 찍으면 수량이 1씩 늘어납니다.
  2. 수량은 − / + 버튼으로 고칩니다. 0이 되면 목록에서 빠집니다.
  3. 카드 결제 완료 · 재고 차감을 누르면 끝입니다. 결제는 모두 카드로 기록됩니다. 화면 아래에 결제번호와 금액이 잠깐 표시됩니다.
상품을 이름으로 찾기

위 검색칸에 “윌크”, “8cm”처럼 일부만 입력하면 카드가 추려집니다. 한 개만 남으면 Enter로 바로 담깁니다.

바코드가 없는 상품

가챠용 키링, 빵스타봉 3종은 바코드가 없습니다. 이름으로 검색하거나 카드를 눌러 담으세요.

휴대폰에서 결제할 때

상품을 담으면 화면 아래에 “담은 상품 N개 · 금액” 바가 뜹니다. 누르면 결제 칸으로 이동합니다.

잘못 담았을 때

비우기를 누르면 이번 결제가 모두 지워집니다. 이미 결제를 완료했다면 환불로 처리합니다.

체험 티켓 팔기 🧾 판매 탭 맨 앞

현장 체험 티켓은 굿즈와 같은 방법으로 팝니다. 재고가 없는 상품이라 숫자가 줄지 않고, 대신 몇 시에 몇 명이 왔는지가 기록됩니다.

티켓가격언제 쓰나
🎟 사전예약 (현장결제)9,000원미리 예약하고 와서 현장에서 결제하는 손님
🎟 현장예약11,000원예약 없이 와서 바로 신청하는 손님
🎟 할인가4,000원할인가로 판매하는 체험 티켓
  1. 판매 탭 맨 앞에 있는 🎟 티켓 카드를 누릅니다. 티켓은 갈색 테두리로 표시됩니다.
  2. 인원 수만큼 누르거나, 오른쪽 결제 목록에서 +로 수량을 맞춥니다. 3명이면 3입니다.
  3. 굿즈를 같이 사면 함께 담아 한 번에 결제해도 됩니다.
  4. 카드 결제 완료 · 재고 차감을 누릅니다. 티켓은 재고가 줄지 않고, 결제한 시각으로 인원이 기록됩니다.

몇 시 인원으로 기록되나요? 체험 시작 시각이 아니라 결제를 누른 시각으로 기록됩니다. 손님이 오면 바로 결제해 주세요.

인원 확인하기

  • 일별 리포트 탭 → 🎟 체험 티켓 — 시간대별 인원에서 시간대별 인원·금액과 사전예약/현장예약 구분을 볼 수 있습니다.
  • 위쪽 요약 칸에 체험 인원과 체험 매출이 따로 나옵니다. 굿즈 수량은 티켓을 뺀 숫자입니다.
  • 구글 시트의 날짜별 보관 시트에도 체험 티켓 시간대별 표가 함께 저장됩니다.
인원을 잘못 넣었을 때

결제 전이면 −로 줄이고, 결제한 뒤라면 일별 리포트에서 그 결제를 환불하고 다시 결제하세요.

재고 탭에는 안 보입니다

티켓은 재고가 없는 상품이라 재고·실사 목록과 입고 목록에 나오지 않습니다. 정상입니다.

티켓 가격이 바뀌면

관리자가 구글 시트 상품 탭의 TK001(사전예약) · TK002(현장예약) 판매가를 고치면 됩니다.

재고 확인과 실사 📦 재고 탭

“전산”은 시스템이 계산한 수량, “실사”는 직원이 직접 센 수량입니다. 두 숫자가 다르면 그 줄이 빨간색으로 바뀝니다.

실사는 하루 두 번 — 오픈할 때와 마감할 때 합니다.

① 오픈: 문 열기 전 진열·창고 수량을 세어 실사 칸에 입력하고 오른쪽 위 🌅 오픈 점검을 누릅니다.
② 마감: 영업이 끝나면 다시 세어 입력하고 🏁 마감하기를 누릅니다.

두 경우 모두 전산재고가 실사 수량에 맞춰지고, 차이는 “조정(오픈 실사 / 마감 실사)”으로 기록되며, 실사 칸은 자동으로 비워집니다. 다음 점검 때 빈칸에서 다시 시작합니다.

실사 입력 방법

  1. 진열대와 창고의 수량을 직접 셉니다.
  2. 상품 줄의 실사 칸에 센 수량을 입력하고 Enter를 누릅니다. 바코드를 찍으면 그 상품의 실사 칸으로 바로 이동합니다. 실사 안 함 필터를 쓰면 아직 세지 않은 상품만 볼 수 있습니다.
  3. 전산과 같으면 차이가 0으로 표시되고 끝입니다. 다르면 줄이 빨간색이 되고 재확인 표시가 붙습니다.
  4. 다 세었으면 목록 맨 아래의 ✅ 실사 완료 저장을 누릅니다. 창에서 🌅 오픈 실사인지 🏁 마감인지 고르고(지금 시각에 맞춰 미리 선택돼 있습니다) 저장하면 전산재고가 실사에 맞춰지고 실사 칸이 모두 비워집니다.

빨간 줄이 생겼을 때

먼저 한 번 더 세어 보세요. 결제를 누락했거나 입고 등록을 빠뜨리지 않았는지도 확인합니다. 빠진 판매·입고가 있으면 먼저 등록하세요.

세어 본 수가 맞다면 그대로 두고 🏁 마감하기를 누르면 됩니다. 마감할 때 전산재고가 실사 수량으로 한꺼번에 맞춰지고, 차이는 “조정”으로 기록됩니다. 영업 중에 한 상품만 바로 맞추고 싶으면 그 줄의 맞추기를 눌러도 됩니다.

저장 버튼은 세 곳에 있고 하는 일은 같습니다. 재고 목록 맨 아래 ✅ 실사 완료 저장, 오른쪽 위 🌅 오픈 점검, 🏁 마감하기 — 어느 것을 눌러도 같은 창이 뜨고, 창에서 오픈/마감을 고를 수 있습니다. 마감을 고르면 그날 날짜 시트 보관까지 함께 합니다.

입고와 상품 추가 🚚 입고·상품 탭

업체에서 물건이 들어오면 판매 전에 먼저 입고를 등록해야 재고가 맞습니다.

입고 등록

  1. 입고 탭에서 들어온 물건의 바코드를 한 개씩 찍습니다. 찍을 때마다 목록에 +1씩 쌓입니다.
  2. 같은 물건이 많으면 드롭다운에서 상품을 고르고 수량을 입력한 뒤 추가를 누르는 편이 빠릅니다.
  3. 메모 칸에 업체명이나 날짜를 적습니다. 예: 세영코리아 추가 입고
  4. 입고 처리를 누르면 재고에 더해집니다.

처음 보는 상품이 들어왔을 때

바코드를 찍으면 “등록되지 않은 바코드” 경고음이 나고, 같은 화면 아래 상품 추가의 바코드 칸이 자동으로 채워집니다. 코드(예: BB028), 상품명, 판매가를 넣고 상품 추가를 누르세요.

인포스페이스 엑셀로 일괄 반영은 전산 수량을 엑셀 값으로 덮어씁니다. 매장 전체 수량을 한꺼번에 맞출 때만 관리자가 사용하세요. 올리면 바뀔 목록을 먼저 보여 주고, 반영하기를 눌러야 적용됩니다.

바코드 점검 📦 재고 탭 위쪽

상품에 붙어 있는 실제 바코드와 시스템에 등록된 바코드가 같은지 확인합니다. 팝업 시작 전과 새 상품이 들어왔을 때 한 번씩 하면 판매할 때 바코드가 안 찍히는 일을 막을 수 있습니다.

  1. 재고 탭 위쪽 🔎 바코드 점검 카드에서 점검 시작을 누릅니다.
  2. 상품을 하나씩 집어 바코드를 찍습니다. 등록된 상품이면 ✓ 상품명이 뜨고 “확인한 상품” 숫자가 올라갑니다.
  3. 등록되지 않은 바코드면 경고음이 나고 목록에 남습니다. 오른쪽에서 어느 상품인지 고르고 “이 상품에 등록”을 누르면 그 자리에서 바코드가 등록됩니다.
  4. 다 찍었으면 점검 끝내고 기록 남기기를 누릅니다. 결과가 구글 시트 바코드점검 탭에 저장됩니다.
확인한 상품 4 / 23

바코드가 등록된 상품 23개 중 4개를 확인했다는 뜻입니다. “아직 확인하지 않은 상품 보기”를 누르면 남은 목록이 나옵니다.

같은 바코드 상품 2개

스틱풍선처럼 두 상품에 같은 바코드가 등록된 경우입니다. 실제 상품의 바코드가 다르다면 한쪽을 다시 찍어 바로잡아 주세요.

바코드 없는 상품

가챠용 키링·빵스타봉처럼 바코드가 없는 상품입니다. 실제로 바코드가 붙어 있다면 찍어서 등록해 두면 판매가 빨라집니다.

점검 중에는 바코드를 찍어도 판매나 입고에 들어가지 않습니다. 판매를 하려면 닫기를 눌러 점검을 끝내고 판매 탭으로 가세요.

일별 리포트와 환불 📊 일별 리포트 탭

날짜를 고르면 그날 몇 건을 결제했고 무엇이 얼마나 팔렸는지 볼 수 있습니다.

💳 매출 대사 — 카드 단말기 금액과 맞춰보기

마감하고 나면 카드 단말기(정산표) 합계와 시스템 매출이 같은지 꼭 확인하세요. 다르면 그날 안에 원인을 찾는 게 가장 쉽습니다.

  1. 일별 리포트 탭 위쪽 💳 매출 대사 칸에 단말기 정산 합계 금액을 숫자로 넣습니다. (쉼표 없이)
  2. 맞춰보기를 누르면 차이와 함께 확인해 볼 곳이 순서대로 나옵니다.
  3. 결과는 구글 시트 매출대사 탭에 날짜·시각·담당자·메모와 함께 남습니다. 몇 번을 맞춰봐도 전부 기록됩니다.
시스템이 더 적을 때

대부분 판매 기록이 아직 구글 시트에 안 올라간 것입니다. ① 이 기기에 남은 기록 → 🏁 마감하기를 누르세요. ② 다른 기기(휴대폰·다른 PC)에서 판 기록도 그 기기에서 마감하기를 눌러야 올라갑니다. ③ 카드만 긁고 시스템에 안 찍은 결제가 있었는지 결제별 판매에서 빠진 시간대를 찾아보세요.

시스템이 더 많을 때

같은 결제가 두 번 들어갔거나, 단말기에서 취소한 결제가 시스템에 남아 있는 경우입니다. 결제별 판매에서 같은 시각·같은 금액이 두 줄 있는지 보고, 취소된 건은 이 결제 환불로 처리하세요.

미리 막는 법

화면 맨 위 배지가 💾 이 기기에 보관 N건이면 아직 안 올라간 기록이 있다는 뜻입니다. 퇴근 전 반드시 🏁 마감하기를 눌러 0건으로 만드세요. 지난 날짜 기록이 남아 있으면 화면 위에 빨간 경고줄이 뜹니다.

마감하기가 끝나면 그 자리에서 오늘 매출 금액이 바로 나옵니다. 그때 단말기 금액과 비교하는 것이 가장 정확합니다.

실사 기록 보기

  • 리포트 화면의 📋 실사 기록에서 그날의 🌅 오픈 실사와 🏁 마감 실사를 각각 볼 수 있습니다. 날짜·시각·담당자와 함께, 전산과 달랐던 상품만 표로 보여 줍니다.
  • 구글 시트에는 실사기록(상품별 한 줄)과 실사요약(점검별 한 줄)으로 쌓입니다. 요약에는 불일치 수와 차이금액까지 들어가서 손실 금액을 바로 볼 수 있습니다.
  • 날짜별로 한눈에 구분됩니다. 점검 한 번이 테두리 상자 하나로 묶이고, 날짜가 바뀌는 자리에는 굵은 가로선이 들어갑니다. 날짜마다 배경색이 번갈아 바뀌고, 오픈은 파란색 · 마감은 주황색 글씨, 차이가 난 줄은 빨간색입니다.
  • 예전에 쌓인 기록에도 같은 서식을 입히려면 구글 시트 위쪽 메뉴에서 재고관리 → 실사 시트 보기 좋게 (날짜별 테두리)를 한 번 누르세요.
  • 날짜별 보관 시트에는 재고 점검 (오픈 · 마감) 표가 들어가 있어, 상품마다 오픈 전산 / 오픈 실사 / 오픈 차이 / 마감 전산 / 마감 실사 / 마감 차이 / 보관 시점 재고를 한 줄에서 비교할 수 있습니다. 오픈이나 마감 중 한 곳이라도 차이가 나면 그 줄 전체가 빨간색입니다.

환불하기

  1. 결제한 날짜를 고르고 결제별 판매에서 해당 결제(시간·금액으로 확인)를 누릅니다.
  2. 펼쳐진 내용에서 상품과 결제번호를 확인한 뒤 이 결제 환불 (재고 복원)을 누르고, 확인 창에서 확인을 누릅니다.
  3. 결제 금액에 줄이 그어지고 환불이 붙습니다. 판매됐던 수량은 재고로 돌아갑니다.

결제 한 건 전체를 환불합니다. 일부 상품만 환불하려면 전체 환불한 뒤 남는 상품을 새로 결제하세요.

오픈 점검 · 마감하기 🌅 🏁 오른쪽 위 버튼

기기에 보관된 기록을 구글 시트에 올리고 실사를 반영하는 버튼입니다. 아침에는 🌅 오픈 점검, 저녁에는 🏁 마감하기를 누릅니다. 휴대폰에서는 아이콘만 보입니다.

버튼하는 일
🌅 오픈 점검기록 업로드 → 오픈 실사 반영(전산재고 맞추기) → 실사 칸 비우기
🏁 마감하기기록 업로드 → 마감 실사 반영 → 그날 날짜 시트로 보관 → 실사 칸 비우기
  1. 오른쪽 위 🏁 마감하기(아침에는 🌅 오픈 점검)를 누릅니다. 버튼 옆 숫자는 아직 올리지 않은 기록 수입니다.
  2. 창에서 오늘 결제 건수·매출과 마감 실사 결과(입력한 상품 수, 전산과 다른 상품과 그 차이)를 확인합니다.
  3. 실사 수량으로 전산재고 맞추기 체크는 켜 두세요. 차이가 나는 상품만 조정으로 기록됩니다. 실사를 다시 확인하고 싶으면 체크를 끄고 마감한 뒤, 나중에 다시 세어 입력해도 됩니다.
  4. 업로드하고 마감을 누릅니다. “업로드 중… 3 / 12”처럼 진행 상황이 나옵니다.
  5. “✓ 업로드 N건 완료 … 실사에 맞춰 N개 상품의 전산재고를 조정했습니다 … 실사 칸 N개를 비웠습니다”가 나오면 끝입니다. 🔒 잠그고 끝내기를 누르세요.
업로드에 실패하면

“업로드하지 못했습니다”가 뜨고 기록은 기기에 그대로 남습니다. 인터넷을 확인하고 다시 시도를 누르세요. 여러 번 눌러도 같은 기록이 두 번 올라가지 않습니다.

마감 전에 창을 닫으면

브라우저가 “사이트에서 나가시겠습니까?”라고 묻습니다. 취소를 누르고 마감하세요. 실수로 닫아도 같은 PC·같은 브라우저로 다시 열면 기록이 남아 있습니다.

마감 후 다시 판매

계속 판매하기를 누르고 평소처럼 쓰면 됩니다. 새 기록은 다음 마감 때 올라갑니다.

실사 칸이 비워집니다

마감이 끝나면 실사 칸이 모두 비워져 다음 날 새로 셀 수 있습니다. 마감 전 실사 결과는 날짜별 보관 시트에 남습니다.

저장 방식 바꾸기: 인터넷이 안정적인 곳에서는 ⚙️ 설정 → 저장 방식 → 바로바로 자동 저장을 고르면 누를 때마다 바로 시트에 올라갑니다. 이때도 마감하기는 그대로 쓸 수 있습니다.

여러 기기를 함께 쓰는 날에는, 마감 전까지 다른 기기의 판매가 내 화면 재고에 반영되지 않습니다. 모든 기기가 마감한 뒤의 시트 숫자가 최종입니다.

문제가 생겼을 때

창을 닫으려는데 “사이트에서 나가시겠습니까?”가 떠요

아직 시트에 올리지 않은 기록이 있다는 뜻입니다. 취소를 누르고 🏁 마감하기를 한 뒤 닫으세요.

“비밀번호가 맞지 않습니다”라고 나와요

숫자를 다시 확인해 입력하세요. 한글 입력 상태에서는 숫자가 제대로 들어가지 않을 수 있으니 한/영을 확인하세요.

“연결 오류”가 뜨고 상품이 안 보여요

1) 인터넷 연결을 확인하고 오른쪽 위 새로고침을 누릅니다.

2) 그래도 안 되면 ⚙️ 설정 → 연결 테스트를 누르고, 나온 결과 화면을 캡처해 관리자에게 보냅니다.

스캐너로 찍어도 아무 반응이 없어요

1) 화면 아무 빈 곳을 한 번 클릭한 뒤 다시 찍어 보세요. 실사 칸이나 메모 칸에 커서가 있으면 그 칸에 숫자가 입력됩니다.

2) 메모장을 열어 찍었을 때 숫자가 나오고 줄이 바뀌는지 확인합니다. 숫자만 나오고 줄이 안 바뀌면 스캐너 설정(끝에 Enter 추가)을 바꿔야 합니다.

상품 목록이 늦게 떠요

1) 이 PC에서 처음 연 경우라면 한 번만 기다리면 됩니다. 다음부터는 바로 뜹니다.

2) 매번 느리다면 ⚙️ 설정 → 연결 테스트에서 응답 시간(예: “1.2초”)과 코드 버전을 확인해 관리자에게 알려 주세요. 코드 버전이 v12-wake보다 낮으면 관리자가 코드를 새로 배포해야 합니다.

결제를 두 번 눌렀어요

결제가 2건으로 기록됩니다. 일별 리포트에서 같은 시간의 결제 중 하나를 환불하세요.

재고가 마이너스(-1)로 나와요

  • 비밀번호 변경: Apps Script의 Code.gs 맨 위 const PIN = '…'; 값을 바꾸고 배포 → 배포 관리 → 연필 → 새 버전으로 배포합니다.
  • 상품 정보 수정: 이름·판매가·바코드는 상품 탭에서 직접 고쳐도 됩니다. 전산재고 칸은 직접 고치지 말고 앱의 입고·맞추기를 쓰세요. 직접 고치면 기록이 남지 않습니다.

  • 시트 설정 반영: 코드를 바꾼 뒤에는 Apps Script에서 setup을 한 번 실행하고 배포 관리 → 연필 → 새 버전으로 배포합니다. setup이 자정 보관과 5분 깨우기 예약을 등록합니다. 예약 목록은 Apps Script 왼쪽 ⏰ 트리거에서 볼 수 있고, dailyExport와 keepWarm 두 개가 있으면 정상입니다.
  • 30초 간격 안내: 구글 자동 실행은 최소 1분 간격이라, 30초 깨우기는 매장 화면이 대신 보냅니다. 화면이 모두 꺼진 시간에는 5분 간격 예약만 동작합니다.
  • 권한 오류: 새 코드를 붙여넣은 뒤 “구글 오류 페이지 / 권한이 승인되지 않았습니다”가 뜨면 setup을 실행해 권한을 허용한 뒤 다시 배포합니다.
  • 연결 확인: 설정 탭의 연결 테스트에서 코드 버전과 연결된 시트 이름을 확인할 수 있습니다.
